# CAD portfolio

Static site. No build step.

## Deploy on GitHub Pages
1. Create repo (e.g. `cad-portfolio`) on github.com, upload ALL files in this folder (keep `assets/` folder).
2. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch `main` / `(root)` > Save.
3. Wait ~1 min. Link: `https://<username>.github.io/cad-portfolio/`
   (Name repo `<username>.github.io` to get `https://<username>.github.io/` instead.)

## Edit
- Email: search `your-email@example.com` in `index.html`.
- Project names/text: edit in `index.html`.
